## 结论

1. **换席并不优于加席（这两条上）**：NB60T5 加席 18.64 / 换席 16.69；IM40 加席 20.22 / 换席 19.23。
   换席把候选权重从 1/6 抬到 1/5，换手惩罚同步放大 —— 加席换手增量 +9.70/+5.88pp/次，
   换席实测 +11.77/+7.85pp/次，与权重换算一致。
2. **信息侧是真的**：换席版池级 RankIC 0.0919 → 0.1115 / 0.1114（+0.020），MaxDD 31.64 → 26.45 / 30.23。
   但全部被成本吃掉。
3. **根因是换手，不是加/换**：现役席换手 0.038~0.105/次（`seat-rescreen-20260924` 表 1b）；
   从加席增量反推，这两条候选的席位换手 ≈ 0.49 / 0.72 次，是现役席的 5~19 倍，
   落入项目档位表的" >40% 全体为负"死区。
4. **四条全部否决**。这两条因子从池级看是 turnover-dead：加、换都不成立。
