# 因子研究总账（截至 2026-10-10）

这份总账把 2026-09-23 以来的研究按“问题—证据—决策”重新整理。它的作用是防止把大量脚本、候选数和平台运行次数误认为策略进展，也防止已证伪的方向被重新挖一遍。

## 先说结论（按用户 2026-10-10 纠正更新）

**主研究目标应是：在池级 C 仍保持饱和的条件下，提高 A。** C 的收益被封顶后，超出满分门槛的余量可以用于承接更高 A 的席位；候选降低净超额或提高换手，并不自动意味着比赛分数下降。

此前本报告把“已测部分形态失败”扩大成“A 侧全部关闭”，结论过度；同时漏掉 10-09 已完成的 LEGMIX 新候选验证。现更正如下：

1. B 是当前分差的最大来源，需要继续观测，但不能用这一点替代主动寻找更好的 A。
2. A 侧应继续保留研究空间；优化对象是平台同口径的席位均值 rawA，不是池级 RankIC，也不是单因子净额。
3. C 是池级约束：只要候选池 rawC 仍不低于 .60，NC 就仍为 1；此时 A 增量无需支付 C 分数代价。不能把月换手 .30 的分母地板误当成不可越过的换手上限。
4. 已失败的具体公式和形态继续留档，但“加席”“高换手高 A”“LEGMIX”等整个方向不能因此关闭。应按池级 C 余量重新评估。
5. 所有新回测仍须先列候选、数量、费用和目的并获明确批准；本次仅修正文档，不运行新测试。

### C 饱和约束下的筛选办法

对同一窗口、同一规则的候选池计算：

```text
rawA_new = 所有有效席位平台 S_i 的算术平均
NC_new = min(rawC_new / .60, 1)
Δ积分 = 44000 × (.20 ΔNA + .35 ΔNB + .45 ΔNC)
```

44,000 系数只适用于当前 10% 新人加成、且总积分未到 40,000 封顶的情形。若基线与候选都 NC=1，则 ΔNC=0，比较 A 增量及 B 时钟影响即可。

- 对每个加席/换席形态，分别报告 ΔrawA、ΔNA、池级 rawC 和距 .60 阈值的余量。
- 按月独立计算 C：报告“基线饱和且候选仍饱和”的月份比例、由饱和掉档的月份数与损失，避免五年均值掩盖边界月。
- C 的 Rex、SR、当月 DD 和月换手全部计算，不能只靠单腿换手或 .30 地板判断。
- 近期窗口与正式五年窗口独立报告；月初预览、历史回测和月末结算不混比。
- size 防作弊、公式去重、未来泄漏预检与 B 变更影响继续作为准入条件。

10-09 preview 的现役 rawC=219.93、NC=1，显示当期深度饱和；但该值基于国庆后极少交易日，不能直接外推为未来稳定余量。应保留它作为观测证据，并用历史逐月结果与后续正式结算判断候选可消耗的 C 空间。

## 目标和现役基线

- 目标：第四届因子大赛年度综合积分榜第一。
- 现役池：5 席、cycle 10、10 组，统一调仓。
- 平台五年净超额：20.30%。
- 每次调仓换手：13.39%；两调仓月月换手约 26.8%，低于 C 段 30% 地板，因此 NC 可满分。
- RankIC / ICIR / 单调性：0.0919 / 0.3675 / 0.99。
- 最新 2026-10-09 preview：排名 85/331，22,648 分；名次变化主要由 C 段月中恢复造成，A 段仍约 40/331，NB 仍为 0。
- 平台余额：1,404.12；gift 已清零。近期 10-06 至 10-07 消耗 34.0，临期额度没有浪费。

分数结构已经验证为：

```text
Comb = 0.20 NA + 0.35 NB + 0.45 NC
NA = min(rawA / 0.08, 0.70)
NB = min(rawB / 0.06, 1.00)
NC = min(rawC / 0.60, 1.00)
```

在当前 NA=.3237、NC=1 的情况下，NB 从 0 到 1 每月约增加 15,400 分；即使 NB 满分，还需要约 264 分的 A 增量才能超过 9 月榜首。因此“找一个更高 IC 的腿”不是当前最主要的矛盾。

## 已经确认的正面进展

### 1. 找到了分差的主因：B 段和周期结构

09-30 榜单显示 `den_b <= 3` 的池全部 NB=0，`den_b >= 4` 的池全部点亮；cycle 1–4 的历史点亮率约 86%，cycle 7–10 的样本全部为 0。`raw_b` 与样本内 RankIC、ICIR、s_i 的相关性很低，不能用样本内指标代替未来 B。

这把研究重点从“继续优化单因子”转成了“确认 B 是席位钟还是池钟，并选择合适的重建周期”。

### 2. 把周期选择做成了完整阶梯实验

同一 5 席池的 cycle 2–6 已在平台完成五年实测。短周期每次换手较低，但全年交易次数更多；净额在 cycle 4–6 之间差异很小；cycle 2/3 的 A 和 DD 更差，也没有额外 B 回报。按同一 B 点亮桶比较，**cycle 4 是当前唯一合理的重建周期**。

这不是收益承诺。周期 4 的优势依赖其他池的历史 B 点亮率，最终仍由 live 快照决定。

### 3. 证明了本地 Python 泄漏问题，并完成修正

09-28/29 的 Python 合成因子曾用取值格式误判索引层，导致按个股对整段窗口做了全样本标准化。截断重算审计确认 3 个候选受影响，修正后与平台记录逐位对齐。之后候选提交必须同时通过 `platform_precheck.py` 和 `repaint_check.py`。

这项工作没有直接产生新因子；受影响候选此前已提交并产生虚高结果，审计将这些结果作废并完成修正重测，避免继续据此决策。

### 4. 建立了平台对齐、成本和运行故障的可复用规则

- 正式本地复现固定为全 A、qfq、`total_mv`、20180101 暖机、label-1、10 组、0.30% 单边成本。
- 平台成本闭合为：`换手/次 × 0.30% × (252/cycle) × 2`。
- 客户端 15 秒读超时不等于服务端未启动；应先查 `last_run_id`，已有 run 时用免费的 `factor_result`，不能盲目重跑。
- 本地 GP 表达式必须先渲染为平台公式；CAL 字段和多级除法链存在明确的退化风险。

这些规则把后续研究从“结果看起来不错”提升到“结果可以审计和复现”。

## 历史失败记录（限定于已测候选与口径，不代表整个方向关闭）

| 路线 | 证据 | 决策 |
| --- | --- | --- |
| 低换手同时提高 A | 3,785 个合成候选、Alpha191 复现和单位换手挖掘均显示高 s_i 与高换手绑定；换手 ≤10% 时 s_i 上限约 .019–.022 | 旧候选集未突破；新算法族仍须按池级 C 约束筛选 |
| 继续压换手 | C 分母有 30% 月换手地板，低于地板不再加分 | 只把换手当成本和安全约束 |
| 追求 size 中性化净额 | 正收益候选几乎都带 size；去均值会被重尾极值击穿，原始排序仍与 size 相关 | 不再做“均值去中性”目标 |
| 加第 6 席 | F-NET01、AlphaGen、行为金融、BM4 合规化和多组 6 席平台测试均为负或明显低于现役 | 已测形态失败；新候选按池级 C 饱和情况重评 |
| 删除低 s_i 席位 | 删除 `size_only` 虽提高 A，池净额降至 18.22%；低 s_i 席位可能贡献 Rex 和低换手 | 不按单席 s_i 淘汰 |
| 整池换成高 IC/高 s_i 同族 | L6/L5 净额 13–15%，换手 31–35%；高 IC、ICIR、SR 与净额在本池反向 | 关闭整池换族 |
| 传统文献异象 | 六条经典异象近五年 t 值均低于 0.7，过不了比赛 A 段门槛 | 停止继续扩展 |
| CAL 族盲搜 | `CT-COMP-ACTIVITY` s_i=.0586，但新族换手多在 27–88%；`CT-VOL-STD10` 平台换手 47.04% | 按池级 C 余量筛选，不由单腿换手直接否决 |
| 榜单高 A 克隆 | 19 个高 A 席位属于同基底近变体；加入现役池的本地三段账全部为负 | 榜单只借鉴结构，不照抄名称或堆变体 |

## 10 月 31 日决策树

1. 零算力读取我方 `den_b / raw_b / nb`，确认 B 是按席位还是按池计数。
2. 同时读取 live `rawC/rc`，解决 C 口径目前仍存在的差异。
3. 如果 `den_b` 跳到 5 且 NB 点亮：放弃 cycle 4 重建；在现役、K10、K20、AMTDISP 之间按 live C 比较。
4. 如果 `den_b` 仍为 0：确认 cycle 10 的结构问题，才进入 cycle 4 重建评估；不能把历史 86% 点亮率当成确定收益。
