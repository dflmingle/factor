## 二、核心结论（决策级）

1. **「不破不立」被否**：243 run × 177 因子席库枚举（5 席 65,780 / 6 席 230,230 组合）最优 = 现役池；
   均换手 ≤15%/次 的 55 条席位里最高 s_i = 0.0244（= 现役 VERIFY10-E）——**现役 A 已吃满免费区上限，唯一能长的是 NB，要「不动 + 时间」**。
2. **换手是裁决变量**：两批 10 次实测中，池换手 ≤14.5% 的（SWAPF +531、BM4 +935）桥为正；
   ≥16.5% 的（V4、PARTT10、AGG6、FSCORE6）全灭——`2×池换手 > 0.30` 后 k 混合口径实算，惩罚吞掉净额优势。
3. **BM4 合规化路线关闭**：BM4（+935）是最高桥但 4 席不合规；两条合规 6 席（+AGG+E 预桥 +308、+FSCORE+E 预桥 −93）
   实测 dk −232 / −979，双口径均不及现役。
4. **FSCORE 判别实验定性**（第 36 条判据）：dkdd −81 未达「明确为正」→「若官方口径为 dkdd 类，高 s_i 补席可用」
   **未获支持**；10 月口径核对的天平数据点已备好。
5. **预桥信用下调**：两条实测比预桥低 −540 / −886（dk 口径），同向乐观 → **越线区预桥只可排序、不可作报批门槛**。
6. **唯一活口 = SWAPF**：5 席合规、换手 13.53%；dk +531 / dkdd −26 / NB 生效 +128——**等 10 月首份快照核对口径后定**；
   10-01~03 删改窗口无新增报批对象。

## 四、方法论沉淀

1. **双口径对立是结构性的**（第 36 条）：低换手席（E/F）拉 dk 但打不动 dkdd（s_i 低）；高 s_i 席（FSCORE/DOWNSIDE/AGG）
   拉 dkdd 但把 dk 打负（换手越线）。6 席补席解不开，只能等官方口径（10 月快照）。
2. **换手三线**：0.30/月 = k 混合免费地板；`2×turn` 进 k=2 分档；>0.30 后惩罚 ∝ 越线幅度。
   **池级换手 ≈ 席位换手均值 +0~0.8pp**（三点校准）。
3. **B 项依赖**：换席路线的正收益全部来自 B 模型（同构假设，池龄 0 时平台闸门给 0）——报批前必须把 B 去掉看一遍。
4. **口径敏感清单**：V4（dk 正 / 官方 DD 口径 −2,990）、SWAPF（dk +531 / dkdd −26）、两条 6 席（dk 负 / dkdd(NB) 正）
   ——**任何单口径结论都要标注口径**。
5. **本地处理的两种已知偏差**：本地逐月机器高估候选边际（T2 本地 +482 vs 平台 ≈−2,330）；
   A 侧代理（池级复合 IC）不是平台 A 口径（平台 A = s_i 算术平均，见第 26 条）。
6. **预桥的界定**：只在「未越线 + 低 s_i 补席」区域可信；越线区（本批两条）系统性乐观，仅作排序。

## 五、工程沉淀（平台操作手册要点）

1. **计费分档**（253 个带 billing 的 run 交叉验证 + 本批对账）：
   **完成 <120s = 4.0；120~180s = 6.0；>180s = 8.0；中止 run 按 4.0 计**。
   （FSCORE 首跑 120.25s 中止 = 4.0；V2 174.1s 完成 = 6.0；237.7s = 8.0。）
   → 重型因子（>120s）真实成本 6.0，报预算要按档；优化（缓存重复算子）可能直接保住 4.0 档。
2. **run 状态码**：运行中 = 1；成功 = 2 或字符串 `"SUCCESS"`；死 = 8。
   - status=8 两形态：**零节点 0.04s**（平台调度抖动，不计费，同 factor 重跑可过）vs **有节点 N 秒中止**（计费）。
   - CLI 报「轮询超时 (600s)」≠ run 失败；**直查链**：state.factor_id → `factor_info`.last_run_id → `factor_result`。
3. **平台抖动处置**：重试（reuse 原 factor 即可；K020 与 AGG 换席均为多次重试后成功）。50% 故障率在其历史上出现过。
4. **槽位**：free 会员「因子分析数量」上限 300；满了会拒新建（不计费）。清理前必须逐件存档（`retired-factors-20260926/`）。
5. **编码坑**：本地 batch 包装器读 CLI GBK 字节流会崩（`PYTHONUTF8=1` 修复）；抓结果用 utf-8/gb18030 双解码；
   写脚本文件用 LF + 无 BOM。
6. **本地预检链**（提交前）：`batch.parse_candidates(..., "python")` 走 lint（唯一 Factor 子类 + 同步 calculate）→
   `py_compile` → 席位定义逐字对照原始提交件（不凭记忆重构）。
