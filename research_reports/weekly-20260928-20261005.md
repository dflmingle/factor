## 二、核心结论（决策级）

1. **A 段在 cycle 10 已经见底。** `NA = min(raw_a/0.08, 0.70)`、`raw_a` = 逐席 `s_i=|IC|×|ICIR|×win` 的均值
   （我方 5 席 `.059267/.021011/.022068/.017983/.009136` ⇒ raw_a .025893 ⇒ NA .3237，与平台快照逐位吻合）。
   B 安全（k ≤1）能拿到的最多 ΔA 是 **+1,280 分/月**（−size_only +K10），只比已确认的 +995 高 **285**；
   再往上就是 NA 封顶路线（L5/L6，ΔA +3,312），净额 13~15%、换手 31~35% ⇒ **C 段彻底封死**。
2. **换席 = A↔C 纯换汇，且汇率对我们不利。** 10-05 两条阶梯合起来给出干净的证据：
   **删谁最"赚 A"与删谁最"亏净额"完全反序**——净额序 **F 20.40 > impact60 19.85 > E 19.45 > size_only 18.22**，
   预测 ΔA 序 **size_only +1,280 > impact60 +1,085 > E +1,018 > F +995**。
   汇率是 **NC : NA = 2.25 : 1**，而现役 NC 已顶到 1.00 ⇒ **C 只能降、不能升**。
3. **加席全线被平台证否（4 次独立实测）**：K10 六席 **19.53（−0.77pp）**、AGP05W 六席 **19.50（−0.90pp）**、
   add4 九席 **17.91（−2.39pp）**、S1/S3 更差。且系统性同现"**RankIC/ICIR 单调升、多头毛超额单调降**"
   （.0919→.1073→.1105→.1146 vs 22.32%→21.13%→20.18%→20.33%）——**池级 IC 高 ≠ 多头净额高**，全年四次独立确认。
4. **C 段：现役是唯一落在免费线内的形态。** `rawC = max(Rex,0)/max(Turn_month,0.30)×SR×(1−1.2DD)`，
   现役 2 个调仓月的月换手 = 2×13.39% = **0.2678 < 0.30 → NC 满分**（live NC = 1.00 的来源）。
   **所有已测改动形态都破线**（连已确认的 −F +K10 = 0.4072、−F +AMTDISP = 0.3362 也破）
   ⇒ 任何编辑都要靠 live rc 买单（C 免费门槛：K10 .850 / K20 .835 / AMTDISP .760）。
5. **胜负手在 B 段，且买不到。** 与榜首 38,313 的差距 **98.3% 来自 NB**；`raw_b` 与席位数量无关、只与样本外质量有关，
   而 in-sample 聚合与 `raw_b` 的相关 **≤0.14**（不能用 in-sample 代理）。所以能做的只有两件：
   **不打断时钟（k ≤1）** 与 **每月快照留档**。第 57 条"cycle ≥7 → nb 全 0"同时提示：B 的点亮时点可能只是**池龄**效应，
   判别器是 **10-31 快照**。
6. **本地模型的适用边界（本窗口最重要的方法论收获）**：
   - **"换席类"方向可信**：F 换席 4 次平台同向；CAL 族本地 s_i 近乎无偏（1.01~1.05）。
   - **"加/删席类"排序不可信**：本地预测 S3 > S1 > add4（13,977/12,997/11,168），平台实测 **add4 > S1 > S3**——完全反转；
     size_only→K10 本地 −574 方向对、**幅度低估**到 −2.08pp。
   - LEGMIX / volstab 增广族本地 s_i 高估 **8~20%**（K5 ×.923 / K8 ×.803 / K20 ×.853）。

## 四、方法论沉淀

1. **三段账是唯一正确的记账结构**：A = 逐席 s_i 均值（**in-sample**）、B = 席位样本外时钟、C = **live** 实现。
   任两段合并都会误判（09-28 两段账误杀 5 条）。
2. **A 与 C 可以反号**：`s_i` 奖励的"高 IC 席位"正是稀释多头顶十分位的那批。任何以净额为目标的选席，都要把 A 增益与 C 损伤**分列**。
3. **换手是唯一能从 in-sample 迁移到 live 的 C 输入**（Rex 不能）⇒ 换手越线是**结构性**代价，不是估计问题。
4. **本地账分级授权**：换席类可信；加/删席类只作排序、不作出入库依据；越线区（月换手 >0.30）系统性乐观。
5. **泄漏纪律（已写入 `AGENTS.md`）**：平台 Python 索引固定 `[date, symbol]`，禁止探测索引层、禁止全样本标准化；
   提交前必跑 `platform_precheck.py` + 逐 .py `repaint_check.py`（截断重算）。
6. **B 段纪律**：`den_b` 按**席位数**计、门槛 4；**换席不清零已点亮的 `den_b`**；若 10-31 点亮，则后续窗口的席位自由度整体放开。
