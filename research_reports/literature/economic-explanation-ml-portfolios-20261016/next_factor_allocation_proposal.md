# 将论文方法用于现有因子池：候选测试方案

论文方法不能对单一静态因子做全截面统一乘法：统一缩放不改变排序，持仓和换手也不会改变。有效用法是把多个因子/席位作为特征输入模型，再按上一验证块的净 Sharpe 归因动态调整各席位暴露。

本地新回测最多 3 个候选，均使用已有 5 年口径、10 日标签、滚动训练/验证、论文 5bp 与项目 30bp 双成本，平台算力为 0。

| 候选 | 输入 | 目的 | 预计本地耗时 |
|---|---|---|---:|
| P1 现役五席动态配置 | SIZE-ONLY、H03-T10、T10-ADD-BM、VERIFY10-E、VERIFY10-F | 直接测试能否在不改变五席成员的情况下，降低池换手并改善净 Sharpe | 15–25 分钟 |
| P2 固定 SIZE + 其余四席动态配置 | SIZE 固定；H03、T10、VERIFY10-E/F 动态 | 把市值公共轴保留为基准，只让高换手/高相关席位接受归因调节，检验是否能减少 T10 成本拖累 | 15–25 分钟 |
| P3 弱独立信息可选层 | 现役五席 + 季节收入惊喜、F-NET01、NL02 | 检验归因是否能自动压低弱或高换手新因子，保留真正有增量的信息 | 20–35 分钟 |

每个候选输出：静态等权基线、未稳定化归因干预、时间稳定化干预、净 Sharpe、换手、月度日频回撤、30bp 净收益，以及每个席位的暴露路径。只有稳定化方案同时满足净 Sharpe 改善、换手下降或不升、30bp 净收益不恶化，才进入下一轮平台候选评估；不会直接改线上池。
