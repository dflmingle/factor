## 二、结论

1. **短周期不涨换手（第三轮再次确认）**：换手/次从 13.39% 单调降到 **5.55%**（c2），月换手 0.281 → 0.583；
   **毛超额单调升**（22.32 → 24.71），但**成本从 2.02% 涨到 4.20%**，两条线在 c5 交叉 ⇒ **净额在 c5 见顶 21.35%**，
   之后 c6/c4/c3/c2 = 21.05 / 20.76 / 20.78 / 20.51 —— **净额对周期不敏感（c4~c6 差 0.3pp 以内）**。
2. **A 侧代价单调恶化，且过 c4 后加速**（`s_i` 代理 = RankIC比 × ICIR比）：
   c6 .702 → −849｜c5 .708 → −831｜c4 **.588 → −1,175**｜c3 **.460 → −1,539**｜c2 **.330 → −1,909 分/月**。
   ⇒ c4 以下每降一格，A 侧多贴 ~360~370 分/月。
3. **DD 是唯一真正惩罚周期的量，且在 c2 跳变**：31.64 → 36.24(c6) → 42.05(c5) → 41.82(c4) → 44.23(c3) → **51.10(c2)**。
   `(1−1.2·DD)` 项：c4 0.498、c3 0.469、**c2 0.387（掉 22%）**。
   注意 **SR 与 DD 反向**：c2 的 SR **1.1591 全场最高**，但 DD 51.10% 也最差 ⇒ 单看 SR 会误选 c2。

## 三、对 10-31 之后重建议程的含义：**c4 是桶内最优**

B 段历史点亮率（第 57 条快照，`den_b ≥ 4`）：cycle 1~4 = **50/58 = 86%**；cycle 5 = 76/130 = 58%；
cycle 6 = 1/3（n 太小）；cycle 7~10 = 0/113。按 `EV = ΔA + ΔC + p_B × 15,400`：

| 重建形态 | ΔA | ΔC（3T） | ΔC（k·T） | p_B | EV（3T） | EV（k·T） |
|---|---:|---:|---:|---:|---:|---:|
| **cycle 4** | −1,175 | 0 | −6,968 | **86%** | **+12,069** | **+5,101** |
| cycle 3 | −1,539 | 0 | −9,396 | 86% | +11,705 | +2,309 |
| cycle 2 | −1,909 | 0 | −12,140 | 86% | +11,335 | −805 |
| cycle 5 | −831 | 0 | −5,930 | 58% | +8,101 | +2,171 |
| cycle 6 | −849 | 0 | −2,286 | 33%（n=3） | +4,233 | +1,947 |

- ⇒ **同一 86% 桶内，c4 在两种 C 口径下都排第一**（c3/c2 的 A 与 DD 都更差，B 却没有额外回报）⇒
  **"重建池应该建 cycle 4"现在是本目录的定案**，不需要再往 cycle 3 / 2 以下试。
- ⇒ **第一轮的"首选 cycle 6"作废**：c6 保 A+C，但 B 点亮率只有 33%（且 n=3）；c4 用 ~326 分/月的 A 代价
  和 0 ~ 1,550 分/月的 C 差价，换回约 +8,000 分/月的预期 B 增量。
- ⇒ **但这个 EV 表仍然只能当排序看，不能当点估计**：
  ① p_B 的分母是别人的池，存在选择偏差（敢建短周期池的人本来就是为了赚 B）；
  ② 15,400 是 **NB 满分**的月值，`nb` 点亮后能拿多少取决于分档；
  ③ C 的两种口径差 3~12 倍，真实值要等 10-31 抄 live `rawC`/rc 才能收窄。
- ⇒ **仍然先看 10-31 快照**：若现役 cycle-10 池的 `den_b` 自己跳到 5 并点亮 `nb`，五条重建全不必做。
- 这仍然解释榜首（13 席 / cycle 5 / nb 1）：它在 A+C 上并不比我们强，**差别就在 B 段能点亮**。
