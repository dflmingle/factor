# HT-A191-LOW 自建变体三窗口测试（2026-09-27，本地）

## 口径
- 数据：本次从 tushare 拉取 2021-01-04..2026-09-07 共 1377 个交易日、5423 只全 A 日线，
  补齐本地缓存缺失的**真** high/low/amount（此前缓存只有 open/close/volume，high/low/amount 均为代理）。
- 复权：以本地 qfq close 为锚，按 scale = close_qfq/close_raw 把 open/high/low 及 VWAP(=amount*10/vol) 调到同一口径。
- 因子：Alpha191 #010/#120/#140 参考实现（010 取负向，120/140 正向）。
- 低换手：lowturn = 1 - MA(TURNOVER,21)/MA(TURNOVER,504)（2018 起全历史算，min_periods=200）。
- 变体：变体 = w*RANK(core) + (1-w)*RANK(lowturn)，w = 1/2（1:1）或 1/3（1:2）。
- 统计：平台 120 个信号日（2021-09-07..2026-08-10），10 日周期，close(t+1)->close(t+11)，
  s_i = |mean rankIC| * |ICIR| * win(IC>0.02)；换手为 top-decile 逐期换手。
- 机器校验：基准行 HT-WREV-LOWTURN-21D 复现 5y .05586 / 1y .03302 / 3m .04310（与既有本地结果一致），
  说明本表数值与既有台账同口径可直接比。

## 判据与结论
- 判据（事前约定）：1y s_i 是否超过现役 LOWTURN 线 .0338（平台）/ .0330（本地）。
- 结果：**全部不达标**。最好的 1y 仅为 HT-A191-010-LOW 1:2 的 .01518，不到判据一半。
- 5y 只有 120-1:2 (.04068) 与 010-1:2 (.03550) 摸到题目对照区间 (.04-.065) 下沿；3m 全部 ≤.0084，远低于 base .0431。
- 加权趋势：三个 core 都是 1:2 优于 1:1，但继续加低换手权重只会收敛到纯低换手（=base 行 .0559/.0330），
  说明 **A191 core 相对低换手分量没有增量信息，混入只会稀释**。
- 结论：不值得提交平台测试；现役 HT-WREV-LOWTURN-21D 仍全面占优。
