## 一、口径与校准

- 席位三窗口指标全部从本仓 run JSON 的 excess / return / RankIC 序列重算（零算力）：
  毛超额年化 = 窗口累计超额 × 25.2 / 窗口期数；净额 = 毛 − 换手×0.1512；SR 用组合收益增量（按席位 5y 平台 SR 比例校准）；
  DD = 窗口内组合净值曲线 MaxDD；s_i = 窗口 RankIC 序列的 |mean|×IR(ddof=1)×胜率(>0.02 同号)。
- 窗口：5y = 全部 120 期（20210907–20260810 信号）；1y = ≥2025-09-07（25 期）；3m = ≥2026-06-07（6–7 期）。
- **5y 校准：现役 5 席的 gross / net / SR / DD 与平台 report 逐位吻合**（例：T10-ADD-BM 22.53%/18.09%/1.0813/27.72%）。
  全库 172 席 |Δnet| 中位 0.8pp（尾部来自 direction=0 与池记录口径差异）。
- 池 = 席位均值；每窗口 `NC = min(1, net×SR×(1−1.2DD)/0.6 / max(k×换手, 0.30))`，
  k ∈ {1:7, 2:46, 3:7}（月调仓次数分布，修正 09-23 报告里直接用单次换手的细节）；
  综合 = `0.20×NA + 0.45×NC(三窗口均值)`；NB 记 0。

## 四、口径敏感性（决定"要不要全换"）

- 三窗口口径沿用 09-23 的代理：**把"窗口全期 DD"当月 DD**（≈30% 量级，对全员都是重罚），
  官方 C 用的是**当月**日频 MaxDD（≈4.59%）。
- 换回官方 DD 口径（席位均值模型）：现役 **20,404**（实测 22,648）｜t10 叠层 **17,414**（NC 0.600 vs 0.883）→ **−2,990/月**；
  部分 t10 化 **20,792** → **+388/月**（与 5y-only 枚举最优一致；协同口径下 22,313 vs 22,406 ≈ −93）。
- 即：**"全换 t10 叠层"在两个口径下符号相反（+675 / −2,990），官方口径优先 → 不做**；
  "部分 t10 化"是唯一两个口径同号为正的方向（+388 / +631），且其两条新席位有 09-24 实测背书（AGG +148.8、G13 +148.3 加第 6 席）。
