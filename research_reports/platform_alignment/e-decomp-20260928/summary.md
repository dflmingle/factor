## 〇、口径修正（本轮首先发现，影响此前所有本地 C 模拟）

**`rawC = max(Rex_ann, 0) / max(T, 0.30) × SR_ann × (1 − 1.2·MaxDD)` 的 max 只钳 Rex 单项，
不是整式钳 0。** 用 285 池平台原生数据（`board-20260928/board_live.json`）反解：
单项钳口径总误差 **0.0000**，整式钳口径总误差 **4751.9**（46 个 `rex<0` 池的 rawC 平台全为 `−0.0`，
整式钳会给它们正 NC）。

- 影响：`rex<0 且 sr<0` 的月份被旧实现错计为正 NC。修正后五席池 60 个月
  **NC 均值 0.757 → 0.628**（36 满 / 20 零 / 4 中）。
- 此前本地批次（turnover-relaxed T1–T5、ab-batch、relaxed-gp 等）的 C 段都带这个偏差，
  方向都是**高估候选的 C**（给不该满的月份塞 NC）；本批起全部用平台 literal 口径。
- 校准证据：T2 本地边际从整式口径的 +482/+655（local/uplifted）收窄到本批 **+152（uplift）**——
  修正后与平台实测（≈ −2,330，桥口径）的差从 ~2,800~3,100 缩到 ~2,480，方向仍偏乐观但已收窄。

## 一、五席 E 分解（60 个月，修正口径）

`E_m = Rex_ann × SR_ann × (1 − 1.2·MaxDD_m)`（月频年化量，重尾）。

**seed（五席）**：E 均值 2.626 / 中位 0.542 / p10 −0.079 / p90 10.28；
NC 均值 **0.628**（36 月满分 / 20 月零分 / 4 月中间）；月换手均值 0.292（每次调仓 0.1458）。

零分月结构：**12 个月组合真负超额（rex≤0）+ 8 个月"赢但路径坏"（rex>0 但 sr≤0）**。
→ C 的损失不是"换手越线"单一主题：20 个零分月里换手分布 0.21~0.60，主因是组合当月的
收益路径（真负 or 震荡）。

**每席边际（seed − drop_X，60 月均值）**

| 席位 | ΔE | ΔNC | ΔT/次 | 单席 only_X 的 NC | 单席 E |
| --- | ---: | ---: | ---: | ---: | ---: |
| size_only | **+0.065** | **+0.0356** | −0.0087 | 0.614 | 2.929 |
| impact60 | −0.078 | +0.0182 | −0.0142 | 0.537 | 1.741 |
| t10_size_plus_impact_bm | +0.421 | +0.0131 | **+0.0537** | 0.476 | 2.584 |
| book_to_market_lf_minus_size | −0.105 | +0.0180 | −0.0122 | 0.554 | 1.923 |
| book_to_market_lf_plus_impact | −0.217 | **+0.0098** | −0.0161 | 0.476 | 1.477 |

读法：
1. **size_only 的 C 边际最大（+0.036）**——去掉它对 NC 的伤害 5 席里最重；但它对 E 的
   边际只有 +0.065（E 均值口径）。8 个"赢但路径坏"月也是 size 家族波动被放大的产物。
2. **t10 是换手主推手**：去掉它，池每次调仓换手 0.1458 → 0.0921（−5.4pp/次），
   E 均值掉 0.42（但中位数只掉 −0.009——均值被极端月支配）。它的 ΔNC 仍 +0.013：
   高换手换来的 E 在多数月份刚好抵住 0.30 线。
3. **bm_plus_impact（VERIFY10-F）的 C 边际最低（+0.0098）**——C 上最接近"白占位"的席；
   对 E 的边际也最负（−0.217）。换席决策里它是最软的席（但注意 A 上它有 s_i 0.0154，
   且 LOO 去掉它会推高池换手 −0.0161 之外的连带变化）。
4. **收益层 size 回归（超额对 size_only 单席超额）**：seed β 0.776、**R² 0.861**——
   五席组合超额方差 86% 与 size 单一轴同源；去掉 size 席后 R² 0.784。
   五席的"独立 E"（非 size 部分）只有残余 14%。

**换手开关效应**：dT ≥ +0.06/次（月换手 >0.41）的全部 dC < 0；dT ≤ +0.02 的
`le30` 组几乎全部 **dC > 0（+72 ~ +284 分/月）**。C 分的分水岭就是"加席后月换手是否越过 0.30"。

**le30 减损组**（wide_s9801_5/10/11/13/14、sizeneut_wide_s9821_6）：低换手（0.09–0.11）、
dE 正（+0.27~+0.51）、**dC 正 +228~+284**——但 s_i 仅 0.009 上下（稀释 A ≈ −236~−257 uplift），
净 ≈ 0；且 **corr_size 0.99~1.00**（纯 size 变体，防作弊不可用）。

（全截面对所有股票同值 → z-score 恒为 0），加入后组合逐月完全不变（dE=dT=dC=0），已识别剔除。

**结论（面向"独门因子"方向）**：
1. **43 条里不存在"干净且正"的候选**：所有 ΔComb>0 的头部 corr_size 0.53~0.71（全 size 家族）；
   le30 组全是 corr_size ≥0.99。"低 size 相关的高质量因子"依旧零命中——与 09-24 的
   全库结论一致，本轮把搜索面换成了"逐月 C 全账"口径，结论不变。
2. **头部名的 ΔComb 几乎全部由 ΔA 撑起**（+514~+950），而 ΔA 用的是"本地 s_i×1.354"
   公式，已被 T2 实测证明系统性乐观（见 §三）。排序应视为"待平台证伪序"而不是结论。
3. **C 段能干的事这轮看全了**：低换手减损型能把 C 拉 +284 分/月，但它们的 A 段天然弱；
   高 s_i 型能抬 A，但 dT 全在越线区（dC −44~−790）。**"高 s_i + 低换手"同时成立者，
   在本轮候选集（含此前 171 条放宽换手重筛）中为 0**——这正是"独门/破解对手"要攻的点。

## 三、校准组对靶（平台已有实测的 5 条）

| 候选 | 本机 ΔComb（uplift） | 平台实测参照 | 备注 |

| T2 | +152 | ≈ −2,330（桥，不含 NB） | 净额 −2.37pp、换手 17.50% |
| T4 | +146 | ≈ −4,960（桥，不含 NB） | 净额 −1.44pp、换手 19.20% |

**F-NET01 池级真实边际（本轮答案）**：作第 6 席 = **−1,109 分/月（不含 NB）**，
其中 ΔA +126、**ΔC −1,235**、dE −0.111、dT −0.008——它是"低换手但弱信号"型，
A 拿的加分盖不住 C 的伤害。与 09-24 K5 结论（−1,806）同向，差异来自 DD/月度口径修正。

**加上 ΔB 稳态的完整桥**（假设其样本外 s_i^B = 回测 s_i，`ΔB = Δraw_b/0.06×15400`）：
ΔA +126 / **ΔB(稳态) +294** / ΔC −1,235 → **合计 ≈ −815 分/月**；首期稀释另计（09-24 蒙特卡洛
−729±413/12 个月，单期仅 23~85 分，被 0.06 上限吸收）。即使全给 NB 稳态，F-NET01 仍是净负。

**T2/T4 偏差的教训**：本地 dA（s_i 公式）高估 + 平台净额退化未在本地模型里足额体现；
故本批所有 ΔComb>0 候选在平台确认前**一律视为待证伪**。

## 四、对 GOAL.md 决策的输入

1. **C 的真实基线应改写**：由"常态 1.00"改为"60 月实测 0.628（本机口径）；36 满 / 20 零"。
   零分月的主因 = 组合当月真负超额（12）或路径坏（8）。**每次 C 提高 0.01 期望 +198 分/月**。
2. **换席门槛新增 E/T 指标**：加席模拟必须报 `ΔE / ΔT / ΔNC` 三项；判据
   "加席后月换手不越 0.30"以外，增加"**ΔE ≥ 0**"（防止 T2 式：本地 A 分掩盖净额退化）。
3. **等价红线**：dT/次 ≥ +0.06 即把月换手推过 0.41（>0.30 线 +37%），dC 必负 −300 以上；
   dT/次 ≤ +0.02 的候选 dC 可正。**换手增量就是 C 的开关，比"档位"本身更本质。**
4. **10-01～03 窗口**：本轮无通过"ΔE≥0 + ΔComb>0 + corr_size≤0.5"三条并集的新增报批对象
   （头部 H00 类 corr_size ≥0.53 且 ΔA 依赖乐观口径）→ 维持不动作，等 10 月首份快照校准
   本地 A/D 段偏差后再议。
