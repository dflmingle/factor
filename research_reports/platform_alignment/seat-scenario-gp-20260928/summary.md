# seat_scenario GP 席位目标挖掘（v1–v4）+ 池级账本终验（2026-09-28，零平台算力）

目标：用"席位场景"目标函数（max{加第 6 席, 5 种换席} 的 A 段结构分 + C 段换手惩罚代理）
跑 GP，找 A 段高 s_i、低换手、非 size 的新候选，再走 L3 六场景真账本终验。

适应度（2026-09-28 晚已修为三段账）：`(a6+b6)·(s_i−mean_s) 或 (a5+b5)·(s_i−seat_s) 取大 − 12000·max(turn−0.13, 0)`，
其中 b6=15400/0.06/6=42,778、b5=15400/0.06/5=51,333（B 段稳态，不乘 uplift）；
三段标定：46 条真实账本 spearman **0.955**（λ 网格最优仍是 12000；旧两段口径 0.862）。
⚠️ 本文件以下 v1–v4 结果与"全负"判决产自**两段账（A+C）**适应度，已按第二节修正。

## 〇、适应度修复（v1 失败原因，均已修）
1. **去截距**：旧版 `c = 1615 − 11004×turn` 让零信号候选拿 +1615 底分 → GP 第 1 代就收敛到
   `s_i=0.00056 / turn=0.008` 的垃圾（fitness 1282）。改为纯惩罚并加观测下限 0.13。
2. **兜底分倒挂**：`periods<100` 的不可评分公式原兜底 −6.0，高于合法低分（最低 −1.2e4）→
   GP 优先演化低覆盖垃圾。seat_scenario 专用兜底改 **−1e6**。
3. **早停**：`stopping_criteria=1.0` 对千级适应度在第 1 代即触发（v1 只跑 1 代）→ 改 **1e12**。

## 四、结论
1. 修复后的 seat_scenario GP 在本机全 A 口径下**未能产出任何过闸候选**：v2 收敛到 size（防作弊红线），
   v3/v4 结构上排除 size 后 s_i 上限 ~0.011–0.015 < 门槛 0.035，L3 全负。
2. 与 GOAL.md 既有结论一致：**"低换手减损型存在、高 s_i×低换手非 size 型"仍为零命中**；
   本轮把搜索面换成了"席位目标 GP + 宽域 357 字段"，结论不变。
3. 已知可用正边际仍只有 size 相关族（H00 +825 / corr_size 0.63，过不了 |corr_size|≤0.5 线）。
