# 重建池综合口径枚举（2026-09-26 夜，零平台算力）

> 问题：把现役 5 席推倒，用全库 s_i 最强 / 综合最优的因子重建池，能不能赢？
> 答案：**不能。全库枚举 5 席 65,780 + 6 席 230,230 个组合，没有任何一条重建路线能赢现役池。
> 最优的「重建」就是把现役池（再）装回来。**

## 一、口径

- 席库 = `platform_si_scan.csv`（243 个 run 的 RankIC 序列重算 s_i）× 各批次 `*.report.csv`（平台 5 年 run 的净额/换手/SR/DD），
  成交 177 个有完整指标的因子（剔除 F-P*、F-6S/8S/1Y/3M-* 等池记录；`seat_library.csv`）。
- 组合评估用与 `swap_size_marginals_20260926.py` 完全相同的公式：
  `rawA = mean(席位 s_i)`；`NA = min(rawA/0.08, 0.70)`；`net/turn/SR/DD = 席位均值`；
  `T* = net·SR·(1−1.2·DDm)/0.6`；`NC(k) = min(1, T*/max(k·turn, 0.30))`，k ∈ {1:7, 2:46, 3:7}；
  `Comb = 0.20·NA + 0.45·E[NC]`（NB=0），`分/月 = Comb·40000·1.10`。
- 两个口径：`plain` = 席位均值、无协同（保守下界）；`syn` = 沿用现役池实测的池化协同（net +2.75pp、SR +0.081，偏乐观）。

## 五、三条结构性原因

1. **NA 封顶 0.70**：把 rawA 从 0.0259 拉到 0.056 以上，「破」的全部上限只有 **+3,311 分/月**。
2. **换手约等于席位均值**：s_i ≥0.045 的 20 条席位换手全 ≥26.6%/次（最高 216.7%）→ 池月换手越 0.53 的地板，
   NC 从 ~1.0 掉到 0.35–0.52；且 A/C 汇率为 2.25:1，高换手换 IC 是负和。
3. **净额与独立性不可兼得**：s_i ≥0.045 里净额 17.5–19.8% 的全是 t10 同族（与现役 T10-ADD-BM 相关 ≥0.93）；
   非 t10 强席（COMBO/OSR2）净额只有 11.6–16.4%，把池 T* 从 0.34 打到 0.23–0.29。
4. 边界数字：**均换手 ≤15%/次 的 55 条席位里最高 s_i = 0.0244（VERIFY10-E，现役第 3 席）** —— 现役 A 侧已吃满「免费区」上限。
   再加上重建 = 新池 = B 计时重置（推迟首份样本外 IC），「不破不立」在本届规则里不成立：**破不起**。
