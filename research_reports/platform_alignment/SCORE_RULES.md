# 平台评分口径（池级）

规则版本：`score-v2-seatbridge-20260924`（v1 → v2 只新增"换席位三段账"，评分公式未变）<br>
适用范围：PandaAI 竞技场池级评分的本地复现与"第 N 席"筛选目标函数。<br>
性质：只读口径说明，不创建因子、不发起平台回测、不读凭证。

脚本侧单一配置源是 [`scripts/platform_score_rules.py`](../../scripts/platform_score_rules.py)；
本地复现校验用 [`scripts/verify_score_rules_local.py`](../../scripts/verify_score_rules_local.py)。
口径改变时递增上面的规则版本并重跑校验，旧版本的分数不可与新版本混比。

## 公式

```
每席   s_i_a = |ic_mean| × |icir| × ic_win_rate          # icir 是 RankIC 序列自己的 IR
A      raw_a = Σ s_i_a / denominator_a                    # 算术平均；denominator_a = 计入席位数
       na    = min(raw_a / 0.08, new_pool_cap)
B      raw_b = 同构均值（池龄 ≥ 1 个月才有样本外序列）；nb = min(raw_b / 0.06, 1.0)
C      raw_c = max(Rex_ann, 0) / max(Turn_month, 0.30) × SR_ann × (1 − 1.2 × MaxDD_month)
       nc    = min(raw_c / 0.60, 1.0)
合计   comb  = 0.20 na + 0.35 nb + 0.45 nc
积分   分数/月 = min(comb × 40000, points_cap) × 1.1(新池加成)
```

汇率（新池加成后）：`+0.01 na = 88 分/月`、`+0.01 nb = 154 分/月`、`+0.01 nc = 198 分/月`。

## 已证实的口径陷阱

1. **IR 用的是 RankIC 序列的 IR**（`mean(RankIC)/std(RankIC)`），不是因子分析页表格里的 Pearson `IC_IR`。
   用后者会把我们池的 NA 低估约 26%（0.2390 vs 0.3237）：逐席偏差 `+59% / +43% / +24% / +14% / −11%`。
2. **胜率是"数期数"的硬计数**：`|{期: 对齐后 RankIC > +0.02}| / 总期数`，且**不被 `direction` 翻转**。
   实例：`size-only` 的 `direction = negative`，但 `ic_mean = +0.0530`、`ic_win_rate = 74/120 = 0.6167`
   （按正向计数；若按 `IC < −0.02` 只有 33/120）。本地筛席一律用 `sign(ic_mean)` 对齐后的 `IC > +0.02` 占比。
3. **A 是算术平均**，加一席只改分母与新增项 ⇒ 加席当且仅当 `s_i_新 > 当前均值` 时抬高 `na`。
4. **两条闸门**：`pool_age_months = 0 ⇒ raw_b = 0`（无样本外序列）；当月期数 `< 2 ⇒ SR = 0 ⇒ raw_c = 0`（因此新池首月 `nc = 0`）。
5. **DD 用当月日频 MaxDD**，不是全期 DD（用全期会把 C 的代价放大 ~10 倍，错口径只能当压力测试）。

## 加席 / 换席位的三段账（核心口径）

**动席位不是只动 NB**：A 立即重算、B 有稳态与一次性稀释、C 重新定价。
`seat_change_bridge()` 落这段账，`seat_change_turnover_points()` 落 C 的换手段。

| 段 | 生效时间 | 公式 | 备注 |
| --- | --- | --- | --- |
| **ΔA** | 立即 | `Δraw_a = mean(新席位集合) − mean(旧席位集合)`；`分/月 = Δraw_a / 0.08 × 8800` | 席位自带 120 期 RankIC 历史，换席当天就变 |
| **ΔB 稳态** | 池龄 ≥ 1 月 | `Δraw_b = Δraw_a`；`分/月 = Δraw_a / 0.06 × 15400` | 池龄 = 0 时整段为 0（闸门） |
| **ΔB 首期稀释** | 一次性 | 新席位样本外序列从 0 开始，被换掉的席位历史作废（`dNB_first`） | 只在池龄 0 时触发 |
| **ΔC** | 立即（当月账本） | `Rex / max(Turn_month, 0.30) × SR × (1 − 1.2·DD)` 的前后差 | 换手 / 净额 / 回撤全变，通常是最负的一段 |

- 现 5 席均值 `0.025893` 是"**不稀释 A**"的门槛；`s_i_新 = 0.06` 的一席约 `+624 分/月`。
- **`raw_a` 是算术平均 ⇒ 换掉弱席比"加同分新席"强约 1.8 倍**（弱席在分母里拖低每一席）。
- C 的换手分母有 `0.30` 免费额度：月换手 0.30 → 0.50，在我们水平下 **−6,320 分/月**，能一口吃掉 A+B 的全部增益。
- 若席位变动发生在月中，还可能把当月调仓样本打到 `<2` 期 ⇒ SR = 0 ⇒ **当月 NC 归零**。
- `insufficient` 的席位不计入 `denominator_a/b`（等于白占位）。
- **排序键必须是 ΔComb（三段之和），任何单段都不能当结论。**

以 2026-09-24 的 5 席池（平台上 `s_i_a`：t10 0.05927 / E 0.02101 / F 0.02207 / h03 0.01798 / size 0.00914，`raw_a = 0.025893`）实测：

| 动作 | ΔA | ΔB 稳态 | 合计（不含 C） |
| --- | --- | --- | --- |
| 换掉 `size_only`，换入 s = 0.0221 | +285 分/月 | +666 | **+951** |
| 换入 s = 0.0334 | +534 | +1,246 | +1,779 |
| 换入 s = 0.0485 | +866 | +2,021 | +2,887 |
| 换入 s = 0.0585 | +1,086 | +2,534 | **+3,620** |
| 只加第 6 席 s = 0.0585（不换人） | +598 | +1,395 | +1,993 |
| 换掉最强的 t10（0.05927）成 s = 0.0334 | −569 | −1,328 | **−1,897** |

（以上数字由 `python scripts/platform_score_rules.py --self-test` 回归：`replace_weakest_points = 3620.06`、`append_sixth_points = 1992.66`、`turnover 0.30→0.50 = −6319.59`。）

## 已知残差与未验证项

- 本地重算的 **IC 序列 ≠ 平台 IC 序列**：本地约 4.6k 行/日、平台池约 5017 只；
  IC 均值差 −2%~+0.2%，胜率因为卡在 0.02 阈值上、每期 3~10 期落在 (0.02, 0.05] 窄带，翻期即可差 ±9/120。
  平台窗口 `20210927..20260826` 与本地信号日 `20210907..20260810` 应为同一组 120 期（平台按 label 结束日标注），
  所以残差主要来自样本口径，而非窗口错配。**结论：本地 A 分量可用于筛选，绝对水平按 ±5% 视为同一口径。**
- 未验证：`new_pool_cap` 的月龄边界（仅在 `pool_age_months = 0` 观测到 0.70）、`points_cap` 的存在与数值、
  `nb` 的分母（`denominator_b`）、`sr_ann` 的具体年化方式。这些项在本地模型里显式留参，不要写死猜测值。
