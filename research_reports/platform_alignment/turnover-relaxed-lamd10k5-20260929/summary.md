# K10-K5V2 加第 6 席：平台同构本地重测（2026-09-29，零平台算力）

背景：发现 `pool5-live-20260928.py` / `pool6-legmix7-20260928.py` / `pool6-lamd10k5v2-20260929.py`
三个 Python 合成文件的 `_date_level` 用了 `str(v)[:4].isdigit()` 兜底，而平台 Python 运行时索引是
**[date, symbol]**（`pool-horizontal-selection-20260921/platform-validation.md` 记录），symbol 前四位
是数字 → 被误判为日期层 → 席位做成了**按股票的时序 z-score**而不是**按日截面 z-score**。
本地 mock 对照：截面口径 5 席换手 13.4% ≈ 平台池记录 13.39%；错误口径 22.4% ≈ 平台代理 24.10%。
⇒ 09-28 LEGMIX7 与 09-29 K10 的平台池级测试都建立在错误口径上，不能用于决策。三个文件已修正。

## 口径

- 席位面板：`ab-batch-20260929/seat_panels_rebuilt.pkl`（`scripts/ab_seat_rebuild_20260925.py` 重跑，
  5 席对齐表同前：T10/E/F/H03/SIZE 净额与平台差 ≤3.5pp；本地重建池 net 23.78% / 换手 14.28%）。
- 候选第 6 席：`LAMD10-K5V2` 公式在本地语言重写（`Add/Div/MA/STDDEV/RETURNS/RANK` 别名层）。
- 组合：逐日截面 1%/99% 缩尾 + ddof=0 Z-score、等权；官方月度 C 账本（日频组合 vs 全宇宙基准，
  月内 Rex_ann/SR_ann/MaxDD，NC=min(1, Rex·SR·(1−1.2DD)/0.6/max(T_month,0.30))）。
- 脚本：`scripts/turnover_relaxed_pool_sim_lamd10k5_20260929.py`；产物 `monthly_/ledger_/daily_*.csv`。

## 结论

1. **席位池正好压着 C 公式的换手地板**（月换手 .292 ≈ .30）：任何高于池均值的换手都会被全额计费，
   所以 K10-K5V2 的 +6.64pp/次换手几乎抵消了 +759 的 A 段增益 → 净 ≈ 0，而不是此前报的"+759 免费"。
2. 结论翻转的根因是**此前的换手基线用错**（错误口径 24.10%/次 vs 真实 13.39%/次）加单位混用。
3. 若要平台实测（可选）：修正版 `pool5`/`pool6` 各一条（≈12.0），对照平台池记录
   F-P260922-08（20.30%/13.39%）；单跑修正版 6 席一条（≈6.0）也可，但对照只能用池记录。
