# 算法族对照：无 size 净额天花板不是 +4.46%（2026-10-09，零平台算力）

**背景**：第 68 条用 GP（374 字段单公式 + `|corr_size|≤0.30` 硬门槛）测出"无 size 净额天花板 +4.46%/年"，
并据此建议关闭"找非 size 强席"路线。本轮把项目内另外两族算法放到**同一把尺子**下（原始面板 top-decile
净额、label = close(t+1)→close(t+1+10)、往返成本 0.006×换手×25.2、corr_size = 与 mcap 的逐日 Spearman 均值），
结论要**部分推翻**：天花板至少 +8.57%，是 GP 的近 2 倍。

## 二、关键发现

1. **算法族决定天花板**：GP 单公式在 box 内是 +4.46%；复合腿搜索（LEGMIX）在同一 box 内是 **+8.57%**。
   第 68 条"天花板 +4.46%、关闭路线"的结论**只对 GP 成立**，应更正。
2. **AlphaGen 那条线依旧是 size**：它的头名 `impact60`（illiquidity 型）净额 +15.81%、换手仅 0.104，
   但 `corr_size = −0.754`——是纯 size 代理（印证第 7 条"高净额 ≈ size 暴露"）。
   `amt60`（−0.664）、`amihud20`（−0.784）同理。**AlphaGen 组合层的净额全部由 size 支出来源承担。**
3. **LEGMIX 之所以能过**：`t_ma5`（5 日均换手，corr **+0.261**，size 无关）与 `amt60`（corr −0.664）
   做**秩等权平均**后，组合的 corr 被拉到 −0.246 ⇒ 两条腿的 size 暴露部分抵消。
   该组合的经济含义 = "高换手 + 高成交额"（流动性/关注度），不是小市值。
4. **年度稳健性**（净额）：`t_ma5+amt60` 2021 +7.9% / 2022 +22.1% / 2023 +17.9% / **2024 +2.0% / 2025 +3.3%** / 2026 +5.2%；
   5 腿版更稳（+9.1/+26.3/+20.7/+9.1/+14.2/+7.3）。**近两年是弱项**，别只看全期。
5. 单腿 `t_ma5` 自身 2025 年 **−15.9%** ⇒ 单腿极不稳，组合（≥2 腿）才可用。
