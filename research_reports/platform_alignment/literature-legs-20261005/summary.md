# 文献腿预筛：Jansen / Swinkels / Zhou (2021) 六条候选

- 日期：2026-10-05（零平台算力）
- 来源：*Anomalies in the China A-share market*, Pacific-Basin Finance Journal 68, 101607（DOI `10.1016/j.pacfin.2021.101607`）
- 脚本：`scripts/_paper_legs_screen_20261005.py`（单腿预筛）、`scripts/paper_legs_20261005.py` + `scripts/_paper_legs_ledger_20261005.py`（池级三段账）
- 口径：与 `_fundamental_prelim` / `_technical_prelim` / `e_decomp` 完全一致——窗口 `2021-09-07..2026-08-10`、全 A qfq、`total_mv`、cycle 10、label-1、10 组、0.30% 单边；`s_i = |mean RankIC| x |ICIR| x win(|IC| > 0.02)`；换手代理 = 顶十分位名单换手/信号日；`corr_size` = 与 `total_mv` 的截面秩相关。

## 1. 结论（一句话）

**六条候选 0/6 过"新强席"门槛**：最强的 `IVOL250` 本地 s_i 只有 **.0149**（现役 5 席本地均值 .0191、K 系 .048~.072、同族弱腿 fam 系 .014~.024），换手虽低但强度不够；池级唯一为正的变体是"加第 6 席 IVOL250"（**+47~+144 分/月**），量级只有整池换席方案 L6（+1,972 分/月）的 1/15~1/40，**不值得动池**。

门槛（第 53 条口径）：**s_i ≥ .035~.045 且换手 ≤ 15%/次** → **0/6 通过**。

要点：

- `IVOL250` 的 **RankIC (.0702) 是六条里最高的，甚至高于我们的 BM 字段 (.0626)**，但 ICIR 只有 .353（BM .352 同档而 win 更低），`s_i` 复合被 ICIR 拖住；这也是第 53 条"纯同族池证伪"的同一机理——**高 IC 不等于高 s_i**。
- 论文的 **EP/SP 在中国样本（2000–2019）最强的一类**，在我们的窗口反而不行：EP 的 IC 只有 .0208 且与 `total_mv` 秩相关 **+.321**（论文用自由流通市值、并剔除最小 30% 微盘，我们的全 A + `total_mv` 口径下价值类被 size 吃掉）。
- `TURN250` 与 `turn_lvl` 相关 **.713**、与 `size_only` **.347** ⇒ 与既有换手/size 族同源，正交性不合格。
- **`INVASSET` 方向 = −1**：论文报告中国"资产扩张 → 高收益"（符号反转，t=−2.61），在 2021-09~2026-08 本地窗口**未复现**（IC .0096 ≈ 噪声，方向与美股一致）⇒ 论文的中国特异符号在这段样本里不成立。

## 4. 建议

1. **本批六条文献腿不进池、不上平台**（0/6 过线，池级最好变体 +144/月 < L6 的 1/15）。
2. **11-01~03 换席窗口维持第 53/54 条决策**：主候选 **L6**、稳健备 **L2c**、退路 **K10 单换**。
3. 若要继续吃这篇论文的红利，应从**方法论**而非字段入手：论文的强项是"月度 decile 多空 + 剔除微盘 + 自由流通市值 + 行业/规模中性化"，而我们的计分是"cycle 10、Top20 排名 IC、`total_mv`、全 A 含微盘"。**同一字段在两套口径下结论可以相反**（EP/INV ASSET 都是例子）⇒ 后续文献映射先做口径折算，再决定是否本地物化。

## 6. 决定性检验：用论文自己的口径复现（2026-10-05，零平台算力）

脚本 `scripts/_paper_convention_check_20261005.py`：**月度 decile 多空、等权、剔除最小 30% 微盘**（论文口径），
窗口 `2021-09-30..2026-08-31`（59 个月）。目的：区分"因子真死了"还是"我们算分口径错配"。

**读法**：

1. **不是口径错配，也不是实现错**。换成论文自己的口径，六条里五条的 L/S 方向全部正确、量级是论文的 60~75%
   （SP .67 vs .93、IVOL .88 vs 1.19、RETVOL .70 vs .90），但 **t 全部落在 0.7 以下**。
2. **论文的 t = 3~5 建立在 240 个月（2000–2019）样本上**；我们的算分窗口是 5 年（120 期 cycle-10）。
   月均 0.7%、月标准差约 8% 的异象，要 t≈3 需要约 20 年。**5 年窗口在数学上装不下 20 年才显著的异象。**
3. 而我们的 A 段目标函数 `s_i = |IC| x |ICIR| x win` **本质上就是一个 5 年窗口的显著性度量** ⇒
   继续挖经典文献异象**不可能过线**，与本批 0/6 是同一件事的两面。
4. **size 锚通过自检**：全 A 小−大 −2.18%/月（t −2.41），剔除最小 30% 后降到 −0.95（t −1.34）——
   与论文"size 主要是微盘/壳价值故事"完全一致，说明本检验的实现路径可信。
5. `EP` 是唯一**真死**的一条（+0.07%/月，t 0.09）；`INVASSET` 全程噪声。

**行动含义**：有效方向只剩两条——① **在 5 年窗口内被直接优化出来的信号**（AlphaGen / 技术目录族即此路径，
已产出 K10/K20/TOPMIX/STD20/AMTDISP，平台 s_i .050~.067）；② **B 段**（席位样本外时钟，占与榜首差距的 98.3%，
与"找因子"无关）。**文献腿挖掘到此收口。**
