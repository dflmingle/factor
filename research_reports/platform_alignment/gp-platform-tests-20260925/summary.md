| 项 | 值 |

**本地算子 ≠ 平台算子**（会影响以后所有提交），必须先用
`scripts/alphaprobe_gp_tushare.py::expression_to_panda_formula` 渲染：

| 本地 | 平台 |
| --- | --- |
| `Inv(X)` | `(1/(X))` |
| `Sub/Add/Mul/Div` | 中缀 `- + * /` |
| `TsStd(X,N)` | `STDDEV(X,N)` |
| `TsMax(X,N)` | `TS_MAX(X,N)` |
| `TsDiv(X,N)` | `(X/MA(X,N))` |
| `TsCorr(X,Y,N)` | `CORR(X,Y,N)` |

字段名渲染为大写（`a_share_market_val` → `A_SHARE_MARKET_VAL`），平台接受。
方向语义（`references/pitfalls.md`）：分组按因子值升序，`--factor-direction 1` 时多头=分组10=
因子值最高十分位，与本地 `score()` 的 topk 一致 → 三条都用 `direction=1`。
