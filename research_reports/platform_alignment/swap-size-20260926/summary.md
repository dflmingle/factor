一句话：**AGG 换 SIZE-ONLY 实测净 19.42%（−0.88pp）、换手 17.54%/次（+4.15pp）、回撤 −1.67pp**；
按月度过 T* 口径折算边际 **+1,172 分/月**（A +795 / B +1,855 / C −1,479），是三条路线里最好的一条，
**但去掉 B 项就是 −684（负）**——换席的 A+B 增益有 **65% 被 C 侧吃掉**（加第 6 席只用掉 31%）。

## 二、口径修正（本轮第二个算术更正）：C 分项要用「净额 + 月度 DD」

`references/competition_rules.md`：`Return_daily` 是**扣除交易成本后**的组合日收益，
`Rex_ann = [(1+R_p)^(252/N) − 1]`（组合与基准分别复合、分别年化再相减）→ **rawC 的 Rex 是净额**，
不是 run 详情里的毛值 `excessAnnualized`。09-24 桥表两处错：

1. 混用「净额 20.30%（基线）」与「毛值 22.57%（候选）」→ 候选的 Rex 虚高 ~1.2pp；
2. DD 用**全期**（31.6%）而不是**月度**（基线 4.59%）→ C 的代价被放大 ~10 倍。

两处叠加把 ΔNC 放大了 4~5 倍。本目录口径：

```
net      = 毛超额 − 换手 × 2 × 0.30% × 252/10
DD_month = 0.0459 × (全期 DD / 基线全期 DD)        # 全期 DD 只做**相对**缩放
T*       = net × SR × (1 − 1.2 × DD_month) / 0.6
NC(k)    = min(1, T* / max(k × 换手, 0.30))，k ∈ {1,2,3}（月分布 7/46/7），期望加权
```

**自校验**：基线 `T* = 0.340`，与 `nc-turn-20260924` 从"首月 0.68 / 三调仓月 0.84 / 常态 1.00"
反解出的 0.337 吻合（两条完全独立的路径）。

| 同上，**不含 B**（池龄 0 的闸门值） | | | | | | | | +795 | 0 | −1,479 | **−684** |

**读法**

1. 换席的 A 项（+795 / +817）与 B 项（+1,855 / +1,905）都比加席大，但 **C 项的惩罚是加席的 4~4.8 倍**：
   换席把**2 调仓月**的 T 从 0.268 推到 **0.351 > T\* 0.329** → 连常态月都掉 NC（1.000 → 0.937）；
   加席的 2 调仓月 T = 0.325 ≈ T\*，仍在**免费区**。
2. 因此三条路线的排序是 **AGG 换席 +1,172 ＞ DOWNSIDE 换席 +956 ＞ AGG 加第 6 席 +821**，
   但差距只有 100~350 分/月，而换席要额外付出「净额 −0.9pp」与「size 席被移除」的代价。
3. **两条路线的正收益都挂在 B 项上**：去掉 B 后加席 ≈ −9、换席 ≈ −684。
   B 项是模型（同构席位均值，假设新席的样本外 ≈ 其样本内 RankIC），**未经平台验证**；
   且池龄 0 时平台闸门直接给 0——所以**现在改席位的当期收益是负的，赌的是之后的 B。**
4. 换席唯一无争议的好处：**降回撤 1.7pp** 与**降 size 暴露**（SIZE-ONLY 是纯 size 席，第 8 条的风险项）。

## 四、执行时点（重要）
