## 〇、先看结论（7 条，都可证伪）

1. **新门槛（S_i ≥ 0.035 & 净额 ≥ 15% & |corr_size| ≤ 0.5）通过者仍然是 0 个**；但门槛里"换手"这一项**量错了对象**：
   真正进 C 分项的是**加席后的池换手**。席位自身换手 27.2% 的 T10-ADD-AGG-IMPACT 只把池换手从
   14.30% 抬到 **17.39%/次**（+21%），不是 27.2%。
2. **换 DD 口径后第 6 席的符号会翻转**。平台 C 分项用的是"**当月**日频 MaxDD"（283 池中位 4.15%），
   不是全期 DD。用日频账本实测我们 5 席"月度日频 MaxDD 中位 **4.59%**"后，t10_size_plus_impact 族 6 条 = **+291 ~ +476 分/月**（K5 逐月实测）。
   旧的 −1,400 ~ −2,600 分/月 全部来自把全期 DD 27.4% 当成月度 DD（K1），那是**错口径**，只能当压力测试。
3. **这 6 条全部过不了 size 防作弊线**：corr_size 0.557~0.711（要求 ≤0.5）。
4. **size 干净的 39 条候选里没有一条月均为正**：最好是 T10-NOMCAP-PLUS-IMPACT **−15 分/月**
   （中位 +701、p10 −2,371、18% 月份为负）= 零期望、纯赌波动。
5. **F-NET01 加席是负贡献**：K5 −1,806 分/月，97% 的月份为负（K1/K2/K3 −1,296 / −542 / −583）。
   它的 +12.76% size 中性化净额是真的，但**换了口径的好不是能加进池子的好**。
6. **10-01~03 加席 vs 晚一期：期望差 ≈ 0**（蒙特卡洛 −729 ± 413 分/12 个月；p10 −21,810 / p90 +19,817）。
   两者都只损失**一个"月末快照"**的稀释，差别只是落在哪个月；早期 rawB 常被 0.06 上限吸收，单期稀释只有 23~85 分。
7. **池级 size 防作弊反向**：加 t10 族不会加深池子的 size（corr_size 0.837 → 0.82~0.83），
   但**只有 F-NET01 把池子 size 中性化净额从 4.97% 抬到 7.33%（+2.36pp）**——它有用，但不是用在"加席提分"上。

ΔNC 用两步 Shapley 中值拆成"换手部分 / 表现部分"。分解与 `stage2.csv` 的 P 加权 ΔNC 对账误差 **2.8e-16**。

   （它的池内相关性 0.82，属"高相关的弱化版"，加权后只是把组合稀释了一遍。）
4. 结论不变：**F-NET01 不加**。它的价值在"降低 size 暴露"，那是防守项，不是提分项。

## 七、边界与风险（不要过度外推）

1. **K5 的水平**靠 `×0.853`（净额）/`×0.941`（SR）对齐平台，这是"本地对平台系统性高估 3.5~5.9pp"的比例校正；
   K5 的**形状**（月度 DD/SR 分布、逐月符号）可信，**水平**依赖这个校正。K2/K3 给出的区间（+102~+522）应视为同一结论的独立复核。
2. **ΔNB 用的是"候选历史 S_i 当未来 S_i^B 的代理"**（表 7 已给灵敏度）；S_i^B 只有 2 条记录起算、小样本天然偏高，
   所以早期 NB 高、后期衰减是结构性现象（§五）。
3. 池级 size 中性化用 `size_only` 面板当 size 轴（与 GOAL §4.8 一致），不是 total_mv 原始值；
   中性化配方是"20 桶桶内均值去中性"，已知会被重尾击穿（见 `sizeneut-gp-20260924`），所以"size 中性化净额"只是**相对**指标。
4. 榜单 preview 快照里没有我们池子的原生行（`my_rank=None`），所以"我们池子当月的 Rex/SR/MaxDD"仍是未知量。
   10 月首份月末快照出来后，应立刻用 §1.2 的公式反解核对（这是零成本的必做校验）。
5. 本报告的 K5/K2/K3 三套都指向同一批候选；但**没有任何一条同时满足"月均为正 + size 达标"**。
