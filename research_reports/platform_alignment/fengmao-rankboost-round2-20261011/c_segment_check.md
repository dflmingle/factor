# 疯猫 RankBoost：C 段独立核验

> 2026-10-11 更正：下文保留原始诊断，但撤销其“官方 C 匹配失败”的结论。原计算用了五年整体复利、周期收益夏普、全期回撤及平均换手乘 2.1，官方 C 却是逐月日频账本。这两个统计对象不同，`NC=0.633` 不能作为与公开 C 失配的证据。正式五年与目标训练窗口重叠，也不能称独立样本外。对手公开 C 属于 2026-10 的六席池，而本地数据截至 2026-09-07；单席历史代理与其没有同范围可比性。修正后的逐月日频账本另存于 `../fengmao-nested-causal-20261011/OLD_FULLFIT_monthly_c_proxy.csv`。旧全窗口拟合仍然不能证明找到了原公式，但依据是样本内拟合与缺少可比验证，不能援引下文的 C 数值。

## 目的

检验当前 `FM_RB_BLEND` 是否不仅能拟合公开的 119 期 RankIC 汇总，还能在 C 段（收益、波动、回撤、换手）上接近疯猫公开池的满分状态。

## 口径

- 信号：`FM_RB_BLEND_formal_signals.npy` / `FM_RB_BLEND_target_signals.npy`。
- 组合：每个调仓日取信号 Top10%，使用保存的未来收益标签重建组合收益和全 A 基准收益。
- 成本：单边 0.30%。
- C 段代理：

  `raw_c = max(annual_excess, 0) / max(monthly_turnover, 0.30) * annual_SR * (1 - 1.2 * max_drawdown)`

  `NC = clip(raw_c / 0.60, 0, 1)`，`C contribution = 0.45 * NC`。

这是单因子独立池的本地代理；平台公开的疯猫 C 是九/六席池级结果，不能视为单因子官方 C。

## 结果

| 窗口 | 年化超额 | 年化 SR | 最大回撤 | 月换手代理 | raw_c 代理 | NC | C贡献代理 |
|---|---:|---:|---:|---:|---:|---:|---:|
| target_119_fit | 144.07% | 4.313 | 10.78% | 1.501 | 3.605 | **1.000** | **0.450** |
| formal_5y | 41.17% | 1.771 | 17.34% | 1.519 | 0.380 | **0.633** | **0.285** |

疯猫公开池快照：`raw_c=97.908`、`NC=1`、`C contribution=0.45`。

## 结论

目标 119 期的 C 段代理确实可以顶到满分，但这是与 RankIC 一样使用全窗口未来标签训练/选择后的样本内结果；正式五年只能得到约 `NC=0.633`，C 贡献少约 `0.165`。因此当前模型没有通过“其它段”验证：它能同时拟合目标窗口的公开 RankIC 和粗粒度 C 满分，但不能在独立正式窗口复现疯猫的 C 段强度。

这说明当前模型仍是目标窗口数值拟合，不足以证明找到了疯猫真实公式；不能据此提交平台。
