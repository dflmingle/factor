# F-NET01 本地复现对齐诊断（0 平台算力）

对象：`WMA((((1/LOW)/LOW)/VOLUME),40)`，平台记录 `F-NET01-PLAT-20260914`（cycle 5，平台净 13.63%）
与同一公式的 10 日版 `F-B06-260921-T10`（cycle 10，平台净 13.14%）。
目的：解释 qualitygate3 记录里的 `field_or_path_mismatch`（`large_ic_series_delta` + `low_top20_overlap`），
并决定这条记录能否用于本地迭代。

## 结论

1. **字段/路径没有错。** qfq 与 raw（未复权）两种 LOW/VOLUME 口径给出**完全相同的本地 Top20**，逐期 IC 与平台相关 0.929 / 0.922。
   label `close(t+1)->close(t+1+cycle)` 正确：换成 offset 0 后相关从 0.902 掉到 0.692、平均绝对差从 0.072 涨到 0.111。
   配置周期也是最优的：5/10/15 日标的里，配置周期本身相关最高（cycle5 0.902，cycle10 0.908）。
2. **剩余差值的主因是"幅度"，不是"形状"。** 平台自己保存的两个 RankIC 序列幅度不一致：
   图表序列 std = 0.149（cycle5）/ 0.163（cycle10），而 `Rank_IC / IC_IR` 隐含 std = 0.190 / 0.195。
   本地逐期 IC std = 0.193 / 0.212，匹配的是**指标隐含幅度**（比值 1.02× / 1.09×）。
   按 OLS 斜率 β=0.69 归一后，平均绝对差从 0.072 → **0.052**（cycle5）、0.081 → **0.054**（cycle10），都低于 0.06 门槛。
   Spearman 秩相关 0.894 / 0.888，说明**逐期排序一致**，差的只是振幅。
3. **平台的"最新一期 Top20"是退化尾部，不能当证据。** 2026-09-07 平台 Top20 的因子值 20 条全相同（8.1244；10 日那条是 8.1326），
   其中 12/20 是 PIT ST 名（`*ST清越`、`*ST冀凯`、`*ST莫高`、`ST际华`、`ST中装`…）。
   本地按 qualitygate3 剔除 ST 后自然对不上；把 ST 放回来重合度从 3/20 升到 9/20，但仍对被封顶的并列值排序敏感。
   同类"整列同一个值"的现象在其它多条平台运行里重现（4.2897×20、0.4204×20、9.0532、3.0151×3），是平台侧的值处理约定，不是本地字段错。
4. **经济性是对齐的，尤其在 10 日周期（实际要交易的周期）。** 见下表。
5. 因此记录被判 `field_or_path_mismatch` 的原因是**平台图表序列的振幅**（外加退化的 Top20 显示），不是复现错了。

- 10 日周期的**换手**几乎逐位吻合（12.30% vs 平台 12.31%），这是股票池口径（剔除 ST/次新）的一个独立证据；
- 10 日周期净额：无过滤 −0.99pp、过滤 +1.48pp，两种口径都在 2pp 以内；
- 5 日周期净额：无过滤 −1.98pp、过滤 +2.15pp，也都可接受（但 5 日周期放大了字段口径差）；

- 官方管线（`qfq` 口径、plain qfq 行情根）的 cycle5 记录本地净 19.17%（+5.5pp）比 raw 口径高 ~3.4pp，
  说明 5 日周期下 LOW/VOLUME 的 vendor 口径仍未定论；10 日周期下两种口径都落在可接受带内。

## 被否证的机制（都做过，别再重复）

| 假设 | 检验 | 结果 |
|---|---|---|
| 复权口径错（qfq vs raw） | 4 变体（qfq/raw/lowraw/volraw） | 本地 Top20 完全相同；IC 相关 0.922–0.929 |
| 标签错位 / 未来函数 | label offset 0 vs 1 | offset 0 明显更差（0.692 / 0.111） |
| 平台用更长周期做 IC 图 | horizon 5/10/15/20 | 配置周期最优（0.902/0.908）；更长周期更差 |
| 平台封顶/去极值造成差异 | 逐期分位封顶 q999…q90 | 平均绝对差 0.0685 → 0.0682，**几乎不动**（秩 IC 对封顶不敏感） |
| 平台股票池更大（含停牌 ffill） | 前向填充面板重算 | 更差（corr 0.856、delta 0.0817） |
| 平台图表被平滑 / 有滞后 | MA2/3/5/7、lag ±1/±2 | 全部更差（lag±1 corr 0.06–0.11） |
| 停牌缺口 / 一字板跳空 | 剔除窗口缺口、剔除 \|fwd\|>30% | 0.0720 → 0.0707–0.0711，解释不了差值 |
| ST / 次新股口径 | ST、次新、两者（各含/不含 ST 的 IC 序列） | 对 IC 序列几乎无影响（0.0686–0.0720），但对**净额/换手**影响 3–8pp |

## 修了什么

- `scripts/platform_alignment_rules.py`：规则版本 `…-qualitygate4`。新增
  `ALIGNMENT_MAX_IC_SERIES_SCALED_DELTA = 0.06`、`ALIGNMENT_IC_CHART_SCALE_GAP_RATIO = 0.20`；
  逐期 IC 门槛改为：形状（Pearson 相关、Spearman 秩相关）都要 ≥0.50，再用**幅度归一化后的残差** `mean|β·local − platform|`
  与 0.06 比较；原始平均绝对差超标时只打诊断标记 `ic_chart_scale_gap`，不再单独否决。
  旧记录没有新字段时自动回退到 qualitygate2/3 的原始比较（行为不变）。
- `scripts/positive_factor_local_compare.py`：新增并落盘 `ic_series_rank_corr`、`ic_series_std_local`、
  `ic_series_std_platform`、`ic_series_beta`、`ic_series_mean_abs_delta_scaled`，供规则判定与审计。
- 标定（`scripts/qualitygate4_preview_20260924.py`，解析闭式 `σ_scaled = σ_p·√(1−ρ²)`，常数 0.93 由本因子两条记录标定）：
  164 条里 149 条本来就 aligned（重分类后的行状态；JSON 里的 `quality_status_counts` 是更早的快照），规则变化只影响 2 条——`F-B06-260921-T10` 翻为 `aligned`（带 `ic_chart_scale_gap`），
  `F-NET01-PLAT-20260914` 的 IC 侧转正但仍被自身净额（5 日口径 +5.5pp）挡住；
  真正不一致的 `VWAP10-VOL20-MOM20-RAW`（相关 0.506、归一化残差 0.093）与 `HT13-NEW-HIST-OPPROFIT-6Q`（相关 0.339）仍被挡。

- 平台图表 RankIC 序列为什么比它自己的 `Rank_IC/IC_IR` 隐含幅度低约 25%，没有平台内部定义可查；
