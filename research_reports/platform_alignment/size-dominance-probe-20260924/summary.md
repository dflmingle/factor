# "净超额是不是被 size 订死了" —— 可证伪检验（2026-09-24）

起因：对 `full374b` 结论的质疑——"搜索范围是不是不够大，净超额怎么可能被 size 订死"。
本目录用三组检验回答，全部离线零算力。脚本 `scripts/size_dominance_probe_20260924.py`。

## 零、先承认取样偏差

第一版只扫了 **GP 净额最高的 200 条**，结果 200/200 的 size 相关都 ≥0.95——这个取样本身有偏：
按净额取 top，而净额目标在 A 股本来就会收敛到小市值。该结果**不构成证据**，已作废。
下面用的是从 32,475 条健康记录里**随机抽 200 条**（去重后 192 条评分成功）。

## 一、池子拆解（最直接的一刀）

| 情景 | 净超额 | 每次换手 |
| --- | ---: | ---: |
| 五席全上（现状） | **+23.80%** | 14.3% |
| 去掉 SIZE 席（剩四席） | +22.86% | 15.2% |
| **五席全部对 size 中性化** | **+1.79%** | 35.9% |
| SIZE 席单独中性化 | **−11.92%** | 83.4% |

五席互相的截面 Rank 相关：SIZE↔H03 0.751、SIZE↔E 0.720、E↔F 0.903。
**掉一席只少 0.9pp，剥掉 size 维度才崩**——说明 size 不是"SIZE 那一席的收益"，
而是**五席共享的公共暴露**。

（注意：中性化后换手从 14.3% 涨到 35.9%，成本项约吃掉 5.4pp，
所以"毛超额"是从 26.0% 掉到约 7.2%——降幅依旧压倒性，但不是全部来自成本。）

## 一·补：中性化配方与稳健性（回应"你怎么做的"）

**实际配方（N1，报告里的 +1.79% 即此）**：

1. **中性化轴** = `size_only` 席位面板 = `−rank(total_mv)`（`financial_factor_local.py:661`
   的 `cap_rank` 经 direction=0 翻转）。与直接用 `total_mv` 分桶等价（单调变换）。
2. 每个信号日，按该轴对当日横截面**等频分 20 桶**。
3. 在**桶内**对面板做**去均值**，取残差——非参数，等于"对 size 做 20 段分段常数回归取残差"。
4. **逐席中性化**（五席各做一次），再对残差 z-score 后等权相加 → 组合 → top-decile 组合、0.30% 单边成本。

换成别的配方，结论不翻转：

| 变体 | 毛超额 | 每次换手 | 净超额 |
| --- | ---: | ---: | ---: |
| 不中性化（现状） | 25.96% | 14.3% | **23.80%** |
| N1 逐席中性化 + 桶内去均值(20) | 7.21% | 35.9% | **1.79%** |
| N2 先合成再中性化 + 桶内去均值(20) | 7.81% | 18.7% | **4.99%** |
| N3 先合成再中性化 + 对 size 秩的二次 OLS 残差 | 7.72% | 15.3% | **5.41%** |
| N4 先合成再中性化 + 对 pct-rank 分桶 | 7.81% | 18.7% | 4.99% |

**读法**：所有变体的**毛超额都从 25.96% 掉到 7.2–7.8%**；净额的差异（1.79% vs 4.99–5.41%）
主要来自换手不同，不是信号存活程度不同。N2/N3/N4 相互吻合（4.99% / 5.41% / 4.99%），
说明结论不是分桶配方或线性假设的产物。

**组合与 size 轴本身的截面 Rank 相关 = 0.8371**（120 个信号日均值）。

**这个检验不能证明什么**：
- 只去了 size 一维，**没有做行业/流动性/波动率中性化**，"size-中性"里仍含其他一切
- 中性化后必须重新选股，换手被动上升，所以净额下降里混了成本项——**毛超额才是干净的对照**
- 中性化后没有重新优化权重，仍用等权

## 二、随机抽样：高净额区里没有非 size 的解

192 条随机候选，按与 SIZE 的相关分桶（净额按各自最优方向计算）：

| \|corr_size\| 桶 | n | 平均原始净额 |
| --- | ---: | ---: |
| ≈0（−0.3~0.3） | 127 | **−9.8%** |
| 0.3–0.6 | 17 | +0.7% |
| 0.6–0.8 | 2 | +15.5% |
| 0.8–0.95 | 1 | +12.8% |
| ≥0.95 | 10 | **+21.2%** |

**净额随 size 对齐度单调上升；size 中性的 127 条平均是 −9.8%。**

- 原始净额 ≥10% 的：**33 / 192**
- 其中与 SIZE 相关 ≤0.5 的：**0 条**

## 三、结论：分两层

1. **在"我们本地能算的 374 字段 × 这两个目标函数"这个空间里**，"高净额 ≈ size 暴露"
   是数据支持的，不是我的臆断。但要注意：**净额目标 + A 股小市值效应，收敛到 size
   本身带有同义反复成分**——真正有信息量的是随机抽样里 0 条非 size 高净额，
   以及中性化后池子只剩 1.8%。
2. **"井"是「目标函数 × 字段空间」的组合，不是字段空间耗尽**：
   - `ic_efficiency`（S_i 目标）→ 收敛到 `amount`/impact 轴
   - `aligned_net_excess`（净额目标）→ 收敛到 size 轴
   - 两个目标各挖到一口我们已有的井，都**没有找到新信号族**

## 四、尚未被证伪的三块（真正的盲区）

1. **size 中性化的净额目标**——这是唯一还没试过的目标函数。若 GP 在
   "去掉 size 后的净额"目标下仍挖不出东西，才算这个空间真的榨干。
2. **`cal_mins` 35 条日内字段**——本地无日内数据，只能上平台，是唯一可能正交的信息源。
3. **剩下的 ~830 个本地无数据字段**（146 条财报边角 + 平台专有）。
