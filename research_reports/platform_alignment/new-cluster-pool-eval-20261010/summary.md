# 新簇本地组合测试（2026-10-10）

本轮使用同一份现役 5 席缓存，做加第六席和替换 SIZE 两类场景。未创建平台因子，未消耗平台算力。正式候选为 K008、K021；U01 作为低换手对照。N34 因本地没有 `OPER_MAIN_PROFIT_TTM` handler，未用代理强行合成。

## 基线

- 现役 5 席：净超额 23.80%，换手 14.30%/次，池 DD 27.41%，NC=1.000。
- 这是历史缓存池级诊断口径，不能替代最新平台池回测；主要用于同口径相对比较。

## 结论

- **K008**：加席 ΔComb −0.0523，替换 SIZE −0.1053；池 DD 约 28.86%/28.05%，换手升至 17.09%/18.49%，没有改善。
- **K021**：加席 ΔComb −0.1865，替换 SIZE −0.2098；池 DD 约 28.49%/27.15%，换手明显升至 23.50%/25.17%，没有改善。
- **U01（1/LOW）**：加席 ΔComb −0.0101，替换 SIZE −0.0324；虽然自身低换手，池级 A/NC 与收益不足以改善组合。
- **N34**：本轮未完成池级测试。平台单因子虽有 12.27% 净超额，但本地缓存没有可验证的 `OPER_MAIN_PROFIT_TTM`，需要补齐 PIT 财务代理后再测。

这些结果只说明当前三种组合方式在历史缓存口径下没有带来边际改善，不能证明候选没有风险分散价值；需要下一轮按最大回撤区间、下跌阶段相关性和替换其他非 SIZE 席位继续检查。
