# lookahead-attrib（2026-09-29）：池合成收益虚高归因 —— 是"软未来"，不是强信号

**一句话**：平台错误运行里 5 席池的 净 46.72%（毛 50.36%）/ RankIC .1678 / ICIR .97，
不是信号变强，而是**全样本标准化（per-stock clip/mean/std 用整段 5 年、含 t 之后的数据算）
把未来信息漏进了每一天的因子值**；主要通道是**全样本均值**（mock +30.3pp/年），
全样本 std 次之（+6.0pp），1%/99% 截尾 ≈ 0。
把同样的"个股相对自身历史"重定义保留、改成**因果**（只用 t 之前数据）后，收益反而**低于**正确截面口径。

## 0. 观测对象

| 来源 | 换手/次 | RankIC | 超额 | 说明 |
|---|---:|---:|---:|---|
| 平台池记录 F-P260922-08（正确几何） | 13.39% | .0919 | 净 20.30% | 平台自身池合成 |
| 平台 POOL5-CTRL（错误口径，09-28/09-29 同一文件） | 24.10% | .1678 | 净 46.72%（毛 50.36%） | Python 合成，`_date_level` 误判 |
| 平台 POOL6（+LAMD10-K5V2，错误口径） | 28.45% | .1709 | 净 43.32% | 同上 |

根因已定：三个 Python 合成文件的 `_date_level` 用 `str(v)[:4].isdigit()` 兜底，
平台 Python 运行时索引是 **[date, symbol]**，symbol（"000001.SZ"）被误判成日期层
→ 最终 `_normalize` 变成按股票的全样本 z-score。本报告只回答"收益为什么虚高、是不是未来函数"。

## 1. 实验设计（零算力，本地 mock）

从 `pool6-lamd10k5v2-20260929.py` 拦截 `_normalize` 之前的 **6 个原始席位信号**（完全同一组信号），
只改最后一步归一化，做 7 种口径对照：

| 代号 | 归一化 | 未来信息 |
|---|---|---|
| `cs` | 按日截面 clip(1/99)+z | 无（正确几何） |
| `ts_exp` | 按股票、因果 expanding z（min252） | 无（只吃 t 之前数据） |
| `ts_expmean_fullstd` | 因果均值 + 全样本 std | 有（std） |
| `ts_fullmean_expstd` | 全样本均值 + 因果 std | 有（均值） |
| `ts_full_nc` | 按股票、全样本 z（无截尾，整段面板） | 有（均值+std） |
| `ts_full_panel` | 按股票、全样本 clip+z（整段面板，2018 起） | 有 |
| `ts_full_eval` | 按股票、仅评估窗口全样本 clip+z | 有（最接近线上 bug） |

样本：全 A 随机 600 只（seed 7），2018-01-02..2026-09-07 面板；评估 2021-09-07 起、
每 10 交易日 122 个调仓日；mock 多头超额 = top-decile 相对当日截面均值。
**绝对水平不可与平台互比（无 ST/成本/真实基准），只做口径间相对比较。**
脚本：`scripts/lookahead_attrib_20260929.py`（`python3 scripts/lookahead_attrib_20260929.py 600`），
明细：本目录 `attribution.json`。

**互镜验证**（mock ↔ 平台，两条口径都各自对上）：

- 正确几何：mock 13.40%/.0774 ↔ 池记录 13.39%/.0919；
- 错误口径：mock 25.79%/.1716 ↔ 平台 CTRL 24.10%/.1678。

⇒ 机制确认：平台那次虚高就是本实验的 `ts_full_eval` 口径，不是别的原因。

## 3. 分解（5 席，mock 年化超额）

```
cs 正确截面                       +26.9%
  └─ 换成"个股相对自身历史"（因果）   +9.8%   ← 信号重定义本身：−17.1pp（RankIC 反而 .077→.097，但多头端更差）
       └─ 均值换成全样本（含未来）   +40.1%  ← 泄漏 +30.3pp（主通道）
            └─ std+截尾也换全样本    +47.9%  ← 再 +7.8pp（其中 std 单独约 +6.0pp，截尾 ≈ −0.5pp）
```

平台观测的净超额跳幅 20.30%→46.72%（+26.4pp）与 mock 的 +21.1pp（47.9−26.9）同量级；
mock 里"泄漏"贡献 +38.1pp，扣掉"重定义"的 −17.1pp 后正好回到 +21pp。

## 4. 机制：为什么全样本均值是主通道

- 因子值 `z_{t,i} = (x_{t,i} − μ_i) / σ_i`，其中 `μ_i, σ_i`、截尾边界都按**整段评估窗口**
  （2021-09..2026-09，含 t 之后）一次性计算。
- `μ_i` 含未来：一只股票未来信号偏高 → `μ_i` 被抬高 → 它在 t 时被算成"低于自身均值"（z 偏负）。
  样本内"未来信号偏高"的股票恰恰是未来收益好的那批 → 每天都凭空获得一层未来方向信息。
- `σ_i` 含未来：逆波动缩放 = 一个用未来信息定标的静态截面倾斜，量级次之。
- 1%/99% 截尾边界同理，但 clip 掉的多是尾部，量级可忽略。
- 平台对"把整段窗口塞进标准化"没有检测（不是 `FUTURE_*`、label 也仍是 t+1→t+cycle+1），
  所以指标一路虚高（IC .1678、ICIR .97、SR 2.06）——属于**软未来/in-sample 泄漏**，
  回测值在实盘（滚动重算）下不可复现。

## 5. 结论与行动

1. 46.72%/50.36%/RankIC .1678/ICIR .97 **全部作废**；正确几何下现役池真实水平
   ≈ 池记录 20.30% 净 / 13.39% 换手 / RankIC .0919 / ICIR .3675。
2. 池级加席决策以修正版几何为准（`../turnover-relaxed-lamd10k5-20260929/summary.md`：ΔComb ≈ −20 分/月，打平）。
3. 规则（防再犯）：任何提交平台的 .py 合成因子，标准化必须逐日截面（或严格 expanding 因果）；
   提交前做"截断自检"——把面板截到某一时点重算，若历史值发生变化即存在未来信息泄漏。
4. 三个池合成文件已修正；09-28/09-29 两个存档（POOL5-LIVE、LEGMIX7 括 6 席）为同一 bug 产物，均已加 ⚠ 作废注。
