# Short-Reversal Research Reports

这是超跌反弹/短期反转研究的精选资料目录。文件由 `sources/huatai-multifactor/series13/` 复制而来，原始资料仍保留在 `sources/` 中。

## 核心研报

1. [华泰系列之四：动量类因子（2016-12-20）](./20161220-华泰证券-多因子系列之四：华泰单因子测试之动量类因子.pdf)  
   直接讨论传统收益反转、换手率加权收益和指数衰减换手率加权收益。
2. [华泰系列之五：换手率类因子（2017-01-09）](./20170109-华泰证券-多因子系列之五：华泰单因子测试之换手率类因子.pdf)  
   提供换手率乖离率、换手率波动和参数敏感性，可用于识别流动性状态。
3. [华泰系列之十三：历史分位数因子（2019-10-15）](./20191015-华泰证券-多因子系列之十三：华泰单因子测试之历史分位数因子.pdf)  
   提供估值和财务质量的历史分位数构造，可作为超跌后的价值/质量确认。

## 配套研报

4. [华泰系列之八：财务质量因子（2018-05-25）](./20180525-华泰证券-多因子系列之八：华泰单因子测试之财务质量因子.pdf)  
   用于基本面质量确认和财务字段选择。
5. [华泰系列之九：一致预期因子（2018-12-14）](./20181214-华泰证券-多因子系列之九：华泰单因子测试之一致预期因子.pdf)  
   与 DLS 论文中的盈利预测修订思路相关。
6. [华泰系列之十：因子合成方法实证分析（2019-01-04）](./20190104-华泰证券-多因子系列之十：因子合成方法实证分析.pdf)  
   讨论等权、IC/ICIR 加权、半衰加权和 PCA 合成。
7. [华泰系列之十一：海量技术因子（2019-05-21）](./20190521-华泰证券-多因子系列之十一：华泰单因子测试之海量技术因子.pdf)  
   重点是价格与成交量背离，适合研究超跌后的价量确认。

每篇报告同时保留同名 `.txt` 文本版，便于全文检索。
