   尽管净额各 +1.59pp / +1.02pp，NC 反而下掉。
2. **预桥 vs 实测**（dk / dkdd）：
   - AGG：+308 / +3 → **−232 / −111**（偏差 −540 / −114）
   - FSCORE：−93 / +129 → **−979 / −81**（偏差 −886 / −210）
   - 两条偏差同向（乐观）、量级 1.5~9 × LOO sd → 越线区预桥系统性高估，此后不作门槛依据。

   全实测池最强），但要样本外表现兑现（10 月后）。**dkdd 路线未获支持。**
4. **对照**：SWAPF（5 席、13.53% 换手）仍是唯一 dk 实测为正的合规方向（+531/-26）；
